# 驗證與交付證據

先復現問題或確認使用者可觀察結果，再由受影響行為和實際風險選最小充分驗證。沿用現有測試／命令；文案等低風險改動可回讀檢查，不為湊覆蓋率寫測試。核心邏輯或可重现 Bug 才考慮失敗測試→最小修正→通過與回歸。

確認證據對應本次變更、版本、環境與實際命令結果，保留失敗的輸出。只以獨立觀測判定行為；不得让正式程式设置证明自身测试通过的状态。工具成功、編譯成功與使用者流程通過分別陳述。文件、關鍵字或格式檢查通過只證明格式，不代替行為驗收；已有充分證據且無新修改、失敗或具體疑點時不重複檢查。

發布、高風險或跨系統聯調時讀 [發布與回歸](references/release.md)。

回報只列結果、關鍵驗證和未驗證項，並給 completion_decision。pass 僅表示本次驗收全部有證據；缺少必要驗證是 partial；驗收實際失敗是 fail。對既有失敗分開記錄，不能刪掉失敗或擅自放寬門禁。
