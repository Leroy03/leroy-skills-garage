# 工作規劃

先利用現有檔案與對話補齊資訊；只詢問會改變範圍、取捨、權限或驗收的缺口。不要預設題數，也不要要求使用者重複已批准的方案。

依本次要求提供所需部分：
- 需求：可觀察結果、範圍、已知限制、必要假設。
- 選型：有實際差異的選項、成本／風險／相容性、推薦與理由；沒有實質取捨就不湊選項。
- 執行：依賴順序、每步產物與驗證；只有存在期限或外部協調時才估排程。
- 未知成本：先定義有邊界的調研／實驗、決策依據與停止條件，再承諾實作。

使用者只要分析時，停在分析。要求實作且資訊足夠時，承接現有批准與專案門禁繼續，不再強制交接另一個規劃技能。

正式或專案規定的 L2/L3 規劃才讀 [變更文件](references/change-records.md)。日常規劃可直接在對話完成，不建立空白流程文件。
